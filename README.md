# phanindraamaardi.github.io

Personal site for **https://phanindraamaardi.github.io/**

## First-time publish

1. On GitHub, create a **public** repository named exactly **`phanindraamaardi.github.io`** (must match your username).
2. Do **not** add a license template if you want an empty repo; or initialize with README and replace contents.
3. From this folder on your machine:

```bash
cd /Users/phanindra.amaradi/test-projects/phanindraamaardi.github.io
git init
git branch -M main
git remote add origin https://github.com/phanindraamaardi/phanindraamaardi.github.io.git
git add index.html styles.css README.md
git commit -m "Initial portfolio site"
git push -u origin main
```

4. GitHub → **Settings → Pages** → Source: **Deploy from a branch** → **main** → **/ (root)** → Save.
5. Wait a few minutes, then open https://phanindraamaardi.github.io/

## Edit content

- Replace placeholder text in `index.html` (About, Experience, Projects, Contact).
- Tweak colors in `:root` at the top of `styles.css`.
